# MAL Assistant Cursor Pack

This package contains project-management files intended to be placed in the
root of a new Cursor repository.

Files:

- `PROJECT_SPEC.md` — full architecture, roadmap, models, APIs, phases, and acceptance criteria
- `AGENTS.md` — instructions and boundaries for Cursor and other coding agents
- `IMPLEMENTATION_CHECKLIST.md` — phase-by-phase build tracker
- `CURSOR_KICKOFF_PROMPT.md` — the first bounded prompt to give Cursor

Recommended usage:

1. Create a new empty repository.
2. Copy these four files into the repository root.
3. Open the repository in Cursor.
4. Paste the contents of `CURSOR_KICKOFF_PROMPT.md` into Cursor Agent.
5. Review the proposed plan before accepting edits.
6. Complete one roadmap phase at a time.
